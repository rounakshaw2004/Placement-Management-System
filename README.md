# Placement Management System

A web-based platform for organizing campus recruitment workflows. The system brings student records, company information, job applications, interviews, and placement results together in one place.

## Features

- Manage student and company records
- Create and review placement applications
- Schedule and track interviews
- Record placement results
- Register and log in to the system

## Teamwork and Coordination

The system supports coordinated placement activities by keeping key recruitment information in one workflow. Student and company records provide a shared reference point, while application, interview, and result records help the placement process stay organized from opportunity through outcome. This makes it easier for the people involved in placement activities to follow progress and keep information consistent.

## Technology Stack

- Java, JSP, and Servlets
- HTML, CSS, and JavaScript
- MySQL database

## Project Structure

The interface is built with JSP pages, while Java Servlets handle application requests and authentication. Styles and client-side scripts are organized in the `css` and `js` directories.
