# Placement Management System

A Java-based web application for organizing campus recruitment activities. It brings student records, company information, job applications, interviews, and placement results into one workflow.

## Features

- Manage student and company records
- Create and review placement applications
- Schedule and track interviews
- Record placement results
- Support account registration and login

## Teamwork and Coordination

The system organizes the information used by students and placement coordinators throughout the recruitment process. Shared student and company records provide a consistent reference, while application, interview, and result tracking help collaborators follow each opportunity from application to outcome. Clear, connected records make it easier to coordinate tasks, communicate progress, and keep placement information up to date.

## Technology Stack

- Java, JSP, and Servlets
- HTML, CSS, and JavaScript
- MySQL

## Project Structure

JSP pages provide the web interface, and Java Servlets handle application requests and authentication. Front-end styles and scripts are organized in the `css` and `js` directories.
